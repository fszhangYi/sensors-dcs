## 1. 一句话

用 **腕部六维力（宏观）+ 指尖触觉（微观）** 组成腕-指协同感知，经本仓库 **hik-sensors 驱动 → DCS 数采 → 停录辅助标注 / 离线特征**，支撑可量化的具身接触任务叙事；算法亮点建立在 **先能稳定录、对齐、对照** 之上，而不是先堆大模型。

---

## 2. 分工（对话结论 × 本仓库映射）

| 角色 | 物理含义 | 本仓库 | 典型用途 |
|------|----------|--------|----------|
| **腕** | 末端整体合力 / 力矩 | `kind: ft` → `ForceTorqueSensor` | 负载、宏观滑移趋势、插装大范围力搜索 |
| **指** | 局部接触分布 / 高频微振动 | `kind: tactile` → `PaxiniTactileSensor` | 接触质量、局部滑移、遮挡下的微调线索 |
| **手** | 夹持行程 / 开合 | 已有 `gripper_read` / `gripper_write` | M1 启发、加握力执行器 |
| **眼** | 场景与接近 | RealSense 等 | 接近段视觉；接触段常被遮挡 → 力/触补盲 |

对话中的「帕西尼 = 六维力」与本仓拆分不一致：**以 `ft` 与 `tactile` 两个 kind 为准**。

```text
        相机（接近 / 全局）
              │
    ┌─────────┴─────────┐
    │   腕 ft（宏观扳手） │
    │   指 tactile（阵列）│
    │   爪 gripper      │
    └─────────┬─────────┘
              ▼
     sensors 驱动（已有）
              ▼
     DCS agent → states/*.jsonl   ← 当前主缺口
              ▼
     对齐 / M1 辅助标注 / 特征与策略实验
```

## 3. 目标课题（可行性排序）

### 3.1 优先：分层滑移检测 + 柔顺加握（性价比最高）

- **故事**：视觉帧率低，滑了才看见；腕部剪剪切力看宏观前兆，指尖高频看局部突变，触发夹爪增力。  
- **为何优先**：与现有夹爪闭环、FT/触觉驱动最贴；不依赖复杂装配夹具。  
- **务实指标**：先保证 DCS 可录、可对齐；实时链路从可达到的 100–200Hz 做起，再挑战对话中的「千赫兹全链路」。  
- **简历口径**：腕-指分层触发 + 相对「只视觉 / 只腕力」的掉落率或反应时延对比（用自己的基线，不抄对话百分比）。

### 3.2 次选：精密装配 / Peg-in-Hole（叙事强、工程重）

- **故事**：小间隙插装时视觉遮挡，接触后靠力/触微调。  
- **可行但勿短期押宝完整 IL+RL**：Elite/CS + 自研栈，力位混合与安全接触成本高于 Franka+ROS 论文环境。  
- **本仓切法**：先录齐视+腕+（可选）触 → 离线接触力曲线与失败模式 → 再谈策略与对比实验。  
- **及格线**：有数据、有实验设计、有相对基线；完整闭环为加分项。

### 3.3 慎重：VLA + 力觉 Token（概念亮、易空）

- 适合作为架构展望或「轻量力觉编码器 + 小任务」模块，**不宜作为唯一交付亮点**。  
- 避免在简历上承诺端到端 VLA 刷榜。

## 4. 与能力计划的咬合（M1）

M1 定义为 **辅助标注飞轮**（非替代金标）：

```text
停录 → 夹爪±FT（±触觉增强）启发预填并落盘
     → 人工确认/改正（E1 金标）
     → 差异回流（阈值 / 下一版辅助模型）
```

腕-指数据进入 `states/` 之后，同一套管线既服务 **求职课题实验**，也服务 **数采质量与抓取成功率统计**。启发默认不覆盖 `task_outcome`。

详见 [capability-metrics-plan.md](capability-metrics-plan.md) §M1、[force-tactile-integration.md](force-tactile-integration.md)。

## 5. 工程落地顺序（本仓库）

| 阶段 | 内容 | 状态意识 |
|------|------|----------|
| **P0** | `ft` / `tactile` 设备进站 YAML；DCS `type: ft|tactile` 只读 agent；写出 `episode_*/states/*.jsonl` | 主缺口 |
| **P0** | Viz 卡片（勿落入 gello 关节条）；注意 FT 超时丢帧、触觉 payload 体积 | 随 agent |
| **P1** | 时间戳对齐（DCS `t_wall` / filter）；腕系↔指尖系标定记入配置 | 对话强调的硬点 |
| **P1** | M1：`grasp_heuristic` + 停录预填 + 差异 sidecar | 计划中 |
| **P2** | 滑移分层检测原型（离线→准实时） | 优先课题 |
| **P3** | 受控夹具上的插装对比实验 | 次选 |
| **P4** | 力觉 token / 策略网络小样 | 展望 |

**硬约束（生态）：** 驱动只留在 `sensors`；DCS / view 只消费，不 fork kind。

## 6. 面试讲解提纲（建议口述 60–90 秒）

1. **问题**：纯视觉在接触与遮挡段失效，需要力觉闭环。  
2. **架构**：腕 `ft` 宏观 + 指 `tactile` 微观 + 爪执行，统一进自研数采（sensors → DCS）。  
3. **工程**：先打通高频多模态落盘与对齐；停录辅助标注形成金标与启发对照。  
4. **课题**：优先分层滑移与柔顺抓取；装配作深度选项；VLA 作扩展。  
5. **指标**：用自己的基线报成功率 / 峰值力 / 掉落率，并讲清同步与标定。

## 7. 边界与诚实声明

- DeepSeek 文中 0.01N、1000Hz、装配成功率等 **未在本仓复现**，仅作方向参考。  
- EtherCAT FT 等仅见规划文档，非现成驱动。  
- 无 DCS agent 时，probe 有数、episode 无数——**亮点工程的第一步是接线，不是新算法仓库**。
